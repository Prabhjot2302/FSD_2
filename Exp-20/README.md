

## Learning Outcomes

1. **Full-Stack Development** - Build a complete web application with Flask REST API and React frontend, understanding the interaction between backend services and frontend UI.
2. **CORS & API Integration** - Configure Cross-Origin Resource Sharing (CORS) in Flask and implement proper API communication between frontend and backend services.
3. **Docker Containerization** - Create multi-stage Dockerfiles and orchestrate microservices using Docker Compose for consistent development and production environments.
4. **Frontend-Backend Validation Alignment** - Implement client-side form validation that mirrors backend requirements, ensuring data integrity across the stack.
5. **CI/CD Automation** - Set up GitHub Actions workflows to automatically test both Python and Node.js services on code changes.
